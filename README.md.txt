# LifeLoop – Personal Productivity Dashboard

## About the Project
LifeLoop is a full-stack web application developed using Python and Django. It helps users manage daily tasks, track personal goals, and maintain daily habits through a simple dashboard.

## Features
- User Login and Authentication
- Create, Update, Delete, and Complete Tasks
- Task Priority: Low, Medium, and High
- Task Due Dates
- Goal Management
- Daily Habit Tracking
- Habit Completion History and Streaks
- Weekly Task Analytics
- Task Progress Statistics
- Search and Filters
- Dark Mode
- Responsive Dashboard

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Python, Django
- Database: SQLite

## Installation and Setup
1. Open the LifeLoop project folder in the terminal.
2. Activate the project's virtual environment.
3. Install the required Python packages.
4. Run database migrations:

   `python manage.py migrate`

5. Start the development server:

   `python manage.py runserver 8001`

6. Open `http://127.0.0.1:8001/` in your browser.

## Objective
The main objective of LifeLoop is to help users organize their daily activities, track goals, and develop consistent habits.
