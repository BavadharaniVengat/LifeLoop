# 🌱 LifeLoop – Personal Productivity Dashboard

LifeLoop is a full-stack web application built with Python and Django to help users organize daily tasks, track personal goals, and build consistent habits through a simple productivity dashboard.

## ✨ Features

- 🔐 **User Authentication** – User login and registration
- ✅ **Task Management** – Create, update, delete, and complete tasks
- 🎯 **Goal Tracking** – Manage personal goals
- 📅 **Due Dates & Priorities** – Organize tasks by due date and priority
- 🌿 **Habit Tracking** – Track daily habits and completion streaks
- 📊 **Productivity Statistics** – View task progress and weekly analytics
- 🔎 **Search & Filters** – Find and organize tasks
- 🌙 **Dark Mode** – A comfortable viewing experience
- 📱 **Responsive Dashboard** – Designed for different screen sizes

## 🚀 Installation and Setup

### Prerequisites

- Python installed
- Git installed
- A terminal or command prompt

### Steps

**1. Clone the repository**

```bash
git clone https://github.com/BavadharaniVengat/LifeLoop.git
cd LifeLoop
```

**2. Create a virtual environment**

```bash
python -m venv venv
```

**3. Activate the virtual environment**

Windows CMD:

```cmd
venv\Scripts\activate
```

**4. Install Django**

```bash
pip install django
```

If a `requirements.txt` file is added to the project, install the dependencies with:

```bash
pip install -r requirements.txt
```

**5. Apply database migrations**

```bash
python manage.py migrate
```

**6. Start the development server**

```bash
python manage.py runserver 8001
```

**7. Open the application**

Visit http://127.0.0.1:8001/ in your browser.
